> **Note on File Formats:** Each activity folder includes both a **Markdown (`.md`)** file (optimized for quick, clean in-browser reading on GitHub) and the **original Word Document (`.docx`)** file (retaining the exact raw layout of the original course artifact).

Within this folder for portfolio activities completed on Coursera, each activity contains an AI-generated `.md` file to help anyone viewing the repository easily read the contents of the activity and see what I accomplished without needing to take extra steps to download or open separate files.

On a personal note, I would highly recommend reading the `.md` converted files directly, as they are much better formatted than the original files they came from. In any case, the original `.docx` files and any relevant supporting materials, if applicable, can also be viewed or downloaded directly within each activity folder.
